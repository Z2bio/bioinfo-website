# Z2Bio Bioinformatics Website

Static bilingual website for Z2Bio / Zero to Biosciences.

## GitHub Pages

This repository is intended to be served from the repository root on the `main` branch.

Live site:

https://z2bio.github.io/bioinfo-website/

## Main Entry

- `index.html` is the GitHub Pages entry file.
- `ChineseWebsites_bilingual_biotech_iris_v26a_cases_carousel.html` is kept as the named source copy of the final page.

## Assets

- `brand_assets/` contains logo and favicon assets.
- `service_poster_previews/` contains service carousel images.
- `case_poster_previews/` contains case carousel images.
